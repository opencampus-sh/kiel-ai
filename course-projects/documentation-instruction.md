# ML Template Repo Project — Guide

**EduHub · opencampus.sh · Project type: Presentation with link
(PRESENTATION_AND_LINK_WITHOUT_DOCUMENTATION)**

> You see this guide in the **My Project** panel once your team is confirmed and
> the project type is set. It describes **what you submit** — it is not a
> mandatory write-up from you.

---

## What you submit

Main evidence: **presentation**, **link to your repository**, and **cover image**.
Written documentation is **not mandatory** (optional upload allowed), since your
code and notes already live in the template repository.

| Deliverable | Required |
|---|---|
| Presentation (file) | **Yes** |
| External link (repository) | **Yes** |
| Cover image | **Yes** |
| Documentation (file) | **No** (optional) |

## In the template repository

Work in the provided
[ML template repository](https://github.com/opencampus-sh/ml-project-template):

- Follow the `INSTRUCTIONS` file in each folder.
- Put your slides in `4_Presentation` (PowerPoint, Google Slides, or PDF).
- Update the main `README` with your project details.

## Presentation

- Tells the **story** of the project and points to the repo for depth/demo.
- Include at least one **"Demo / link"** slide with the repo URL.
- About 8–20 slides recommended; formats: PDF, PPT/PPTX, ODP — max. 25 MB.
- Upload in EduHub under **Presentation**.

## External link (repository)

- Publicly reachable (HTTPS), no undocumented login wall.
- Enter the link to your template repository in the **External link** field.

## Cover image

- Visual entry point, e.g. taken from one of your slides; at least ~800×450 px.
- Upload in EduHub under **Cover image**.

## Pre-submission checklist

- [ ] Presentation uploaded
- [ ] Repo link tested (incognito / different browser) and entered in the field
- [ ] Cover image uploaded
- [ ] Deadline met — **one** team member submits for the whole team
